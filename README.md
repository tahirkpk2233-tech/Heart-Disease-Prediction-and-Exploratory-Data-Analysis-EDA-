# Heart Disease Data Analysis and Preprocessing

Exploratory data analysis (EDA) and data preprocessing on a heart disease dataset, preparing it for machine learning.

## Dataset
- heart.csv: 918 patient records, 12 features
- Features include Age, Sex, ChestPainType, Cholesterol, and others
- Target: HeartDisease (0 = no, 1 = yes)

## What I Did
- Explored the data: distributions, missing values, and outliers
- Visualized relationships between features and heart disease
- Cleaned the data and handled invalid values
- Encoded categorical features
- Scaled numeric features so the data is ready for modeling

## Tools
Python, Pandas, NumPy, Seaborn, Matplotlib, scikit-learn, Jupyter Notebook

## Files
- heart.csv: dataset
- The Jupyter notebook: full analysis with code and charts
